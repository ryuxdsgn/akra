# Akra tutorials for beginners

Akra helps you plan and make faceless YouTube Shorts (short videos with no person on camera). These tutorials assume you are not a programmer. Each one has numbered steps and prompts you can copy.

## Step 1: pick your group

| | Group 1: chat apps | Group 2: agent apps on your computer |
|---|---|---|
| Apps | ChatGPT, Gemini, Claude.ai | Claude Code, Antigravity, Codex |
| Where it runs | In your browser or phone app | On your own computer |
| Setup time | About 10 minutes | About 30-60 minutes (you install some tools) |
| Pick a niche, plan a channel | Yes | Yes |
| Ideas, scripts, storyboards | Yes | Yes |
| Title, description, hashtags, monetization check | Yes | Yes |
| Make the voiceover | No | Yes |
| **Render the video (MP4)** | **No** | **Yes** |
| Upload and schedule on YouTube | No (you upload by hand) | Yes, only after you approve |

If you only want to plan and write, start with Group 1. If you want finished videos, use Group 2. You can do both: plan in a chat app, then bring the script to Group 2.

## Before you publish anything

Whatever app you use, YouTube can refuse to pay for low-effort videos. Read [youtube-policy.md](../../skills/akra/references/youtube-policy.md). In short: have your own angle, give a source for every fact, say when AI was used, answer "made for kids" honestly, and watch every video yourself before it goes live.
